# telegram-ai-consultant

Telegram-бот для малого бизнеса: отвечает клиентам по материалам компании и собирает заявки менеджеру. Работает с GigaChat или любым OpenAI-совместимым API.

## Структура

- `bot.py` — диалог на aiogram 3: ответы на вопросы, заявка через машину состояний (`Lead`), проверка телефона, отправка заявки менеджеру, журнал в `logs/dialogs.csv`.
- `llm.py` — провайдеры модели: `gigachat`, `openai`, `fake`. Если `GIGACHAT_MODEL` не задан, берётся первая доступная по ключу модель.
- `knowledge.md` — материалы компании, единственный источник фактов для ответов.
- `check_models.py` — выводит модели GigaChat, доступные по ключу.
- `tests/test_bot.py` — весь сценарий без сети: Telegram подменён фальшивой сессией, модель режимом `fake`.

## Команды

```
pip install -r requirements.txt
cp .env.example .env
python bot.py
pytest
docker compose up -d --build
```

## Правила

- Бот не выдумывает: всё, чего нет в `knowledge.md`, переводится на менеджера. Не ослаблять эту часть промпта.
- `.env` с токенами никогда не коммитить.
- Под другой бизнес меняется только `knowledge.md`, код при этом не трогается.
- Любое изменение диалога сопровождается правкой `tests/test_bot.py`.
